## 📐 How I approach a data project

I start with the data contract and the core business problem. I focus on making pipelines reproducible, separating raw data from curated models, enforcing schema and business-rule validation, and documenting architectural decisions. A pipeline is not complete when it runs once; it must be testable, observable, and safe to backfill.
